J.A.R.V.I.S. is an advanced, real-time conversational AI assistant featuring a premium user interface and seamless cross-platform accessibility. Designed with robust memory and adaptive learning capabilities, it acts as a highly responsive, personalized virtual companion.

Core Features

Voice-Driven Interaction: Integrates precise Speech-to-Text (STT) and Text-to-Speech (TTS) for natural, lightning-fast spoken conversations.

Cross-Device Accessibility: Runs a local host server on a PC that can be instantly accessed and controlled via any web browser on an Android device.

Continuous Learning: Dynamically absorbs new information, expanding its knowledge base organically based entirely on what you teach it.

Persistent Memory: Built with a strong retention architecture to permanently store user facts, context, and preferences, recalling exact details precisely when needed.

Premium UI/UX: Features a sleek, modern visual design for an intuitive and immersive user experience.



**Installation and Setup**

1. Clone this repository to your local machine.
3. Open the new `.env` file and replace the placeholder text with your actual Groq and Tavily API keys.
4. Run `python run.py` to start the J.A.R.V.I.S. server.
